## RF Cloner (433 MHz) — D1 Mini

A microcontroller-based RF signal cloner built on the Wemos D1 Mini, designed to capture and retransmit 433 MHz RF remote signals using dedicated receiver and transmitter modules.

## Features
- Raw 433 MHz RF signal capture
- Accurate signal retransmission
- Button-controlled operation
- Simple and reliable workflow

## Hardware Requirements
- Wemos D1 Mini
- 433 MHz RF Receiver
- 433 MHz RF Transmitter
- 2 Push Buttons

## Pin Configuration
- RF Receiver: D2
- RF Transmitter: D1
- Capture Button: D5
- Send Button: D6
